# 릴스 영상 홈페이지 적용 설계 (2026-08-26)

릴스 최종본(`~/Desktop/naraka/reels/07-ae/naraka_reels_fianl.mp4`, 80초, 1080×1920, 24fps, 사운드 포함)을
나라카 홈페이지에 하이브리드 방식으로 적용한다: 히어로엔 무음 발췌 스크럽, 풀 영상은 전용 페이지.

관련 스펙: `2026-08-24-naraka-home-design.md` §4.4 (여정 소스를 릴스 발췌로 변경한 결정의 구체화).

## 1. 히어로 — 액자 다이브 스크럽

- 최종본 **74.5~80초 구간을 역순 프레임**으로 추출해 기존 `ScrubJourney` frames 모드에 공급한다.
  역재생 결과: 인스타 게시물 → 책상 줌인 → 액자 다이브 → (셔터 플래시) → 단체샷.
- 코드는 이미 manifest 기반(`public/journey/manifest.json`)으로 완성 — **에셋 생성 + manifest 작성이 핵심 작업**.
- 프레임 밀도: 24fps 원본에서 2프레임 간격 다운샘플 → 약 66장 WebP.
  - 데스크톱 세트: 세로 1080 기준, 모바일 세트: 세로 720 기준. 목표 총량 3~5MB.
- 데스크톱 표시: 9:16 프레임을 canvas 중앙에 letterbox 배치, 양옆은 다크 오크 계열 배경(액자 무대 폴백 톤).
- 기존 안전장치 유지: prefers-reduced-motion 정적 폴백 / 재방문 축약 / 건너뛰기 앵커.
- 스크럽 종점(단체샷)에서 환영 카피가 페이드인된 뒤 홈 본문으로 이어진다.

## 2. 홈 스토리 섹션 — 인스타 프레임 티저

- 홈 페이지 달력 아래에 "나라카 채용 설화" 섹션 신설.
- AE 소재(`06-ae-assets`)의 **인스타 프레임 목업**을 재활용해, 프레임 창 안에 영상 포스터(대표 컷) + 재생 버튼 배치.
- 탭/클릭 시 `/story`로 이동한다. 홈에서 인라인 재생하지 않는다(80초+사운드는 전용 페이지 몫).
- 스타일: 한지 시트(`.home-paper`) + 테이프, 나라카 앤틱 토큰 준수. UI 문구에 이모지 금지.

## 3. `/story` 전용 페이지 — 채용 설화

- 상단: 풀 영상 플레이어 — 클릭 재생, 사운드 온, `preload="none"` + 포스터.
  - 모바일: 9:16 풀폭. 데스크톱: 인스타 프레임 목업 안에서 재생.
- 영상 재인코딩: H264 CRF 23 + AAC 128k, 목표 20~30MB. `public/story/`에 정적 호스팅(Vercel CDN).
- 하단 구성:
  1. 3막 소개 — 멜(강시)·바나(뱀파이어)·미호(구미호), 이력서→사고→응징→감옥→도장 구조.
     문안은 나라카 캐논([[naraka-lore-canon]]·채용 설화 캐논) 어휘 준수, "카페=감옥=직장" 농담 유지.
  2. 치비 원화 17장 캐러셀 — 인스타 캐러셀 순서(`1.png`~`17.png`), 지연 로드.
  3. `@naraka_concafe` 인스타 링크 버튼.
- 헤더/푸터 내비에 "설화" 항목 추가.

## 4. 비범위·확인 사항

- 홈에서의 영상 인라인 재생, BGM 반영 전 재렌더 대기 등은 비범위 — 현재 최종본 그대로 사용하고,
  BGM 추가 렌더가 나오면 동일 경로 파일 교체로 갱신한다.
- **작가 동의**: 치비 원화·릴스의 웹 사용 동의 확인은 사장님 담당(진행과 병행, 머지 전 확인).
- 작업 위치: `naraka-home-wt` 워크트리(feat/naraka-home). 게이트: `npm run build` + lint + Playwright 실앱 검증.
