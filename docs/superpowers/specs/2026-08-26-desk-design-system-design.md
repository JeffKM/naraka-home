# 영상 실측 디자인 시스템 "옥자의 책상" + 구성 개편 설계 (2026-08-26)

릴스 최종본에서 실측한 팔레트·조형 언어로 카페 홈 디자인 시스템을 전면 교체하고,
설화 콘텐츠를 소개 페이지로 통합한다. 원칙: **원화 스타일 "흉내" 금지 — 실측 색과
실에셋(영상 컷아웃·원화·인스타 프레임)만 사용**한다 (1차 "종이 위의 요괴들" 폐기 교훈).

관련: `2026-08-26-reels-homepage-design.md` (릴스 적용 — 이번 개편의 전제),
`2026-08-24-naraka-home-design.md`.

## 1. 콘셉트 — 페이지 전체가 "밤의 책상 위"

엔딩 장면 메타포를 사이트 구조로: **배경 = 인스타 다크/밤의 책상, 콘텐츠 = 책상 위
이력서(양피지) 시트, 섹션 라벨 = 백묵 명패**. 히어로 스크럽(인스타→책상→액자 다이브)과
시각적으로 한 몸이 된다.

컴포넌트는 새 토큰으로 일괄 이관하고 잔존 참조가 없어야 한다.

## 3. 조형 언어 — 영상 소품 → 컴포넌트

- **이력서 시트**: 기존 `.home-paper`(불규칙 radius+테이프+얼룩) 구조 유지, 색만 실측값으로.
- **명패 라벨 `.home-plate`(신설)**: 섹션 제목을 `@naraka_concafe` 명패처럼 — slate 바탕,
  chalk 글씨, 살짝 기운 배치.
- **인스타 프레임**: 미디어 컨테이너 표준(티저·플레이어 기적용).
- 빗금 tally·도장·기존 원화 컷아웃 장식 유지. 서체(Hahmlet→Gowun Dodum→Gaegu)·CSS
  노이즈 질감 유지.
- 적용 범위: **(home) 카페 홈 라우트만**. /event 주식앱·어드민 콘솔 무변경.

## 4. 장식물 컷아웃 라이브러리 (영상 발췌, 최대한 다양하게)

영상 프레임에서 소품을 컷아웃해 `public/home/deco/`에 추가하고 `HomeDeco`·푸터·서브
페이지에 분산 배치한다. 기존 6종(위스프 2·술 장식·검은 고양이·박쥐·돈주머니)과 중복되지
않는 것 우선. 후보(원본 시각은 대략값 — 구현 시 가장 깨끗한 프레임 선정):

- 추출 기법: 플랫 컬러 경계색 팔레트 BFS + 먹선은 채색면 7px 이내만 유지 + 최대 성분
  유지 (원화 컷아웃과 동일 파이프라인). 로컬 델타 flood 금지(안티앨리어스로 전멸).
- 목표: 신규 12종 이상, 총량 ≤200KB(webp). 각 컷아웃은 QC 프레임덤프로 확인.
- 배치 원칙: 여정 히어로·콘텐츠 본문은 침범 금지(기존 "여정 칸 장식 금지" 유지),
  xl 여백·푸터·페이지 코너 위주. 과밀 금지 — 페이지당 3~5개.

## 5. 구성 개편 — 설화의 소개 통합

- `/about` 전면 재구성: 영상 플레이어(상단) → "지옥=감옥=직장" 이야기 → 요괴들
  (기존 CAST 카드에 3막 채용담 문안 통합) → 원화 캐러셀 → 인스타 링크.
- `/story` 라우트 삭제, 내비 "설화" 항목 제거, 홈 티저 링크는 `/about`으로.
- 홈 티저 섹션 유지(새 팔레트 적용).

## 6. 검증·확인 사항

- 게이트: `npm run build` + `npx eslint src` + Playwright 실앱 전 페이지 순회 스크린샷
  (홈·소개·오시는 길·메뉴·스태프·공지·이벤트·게임 + 모바일 홈).
- 구 토큰 잔존 참조 0건 (`grep -r "home-gold\|home-teal\|..."` 확인).
- **사장님 컨펌이 머지 조건**: 현행 앤틱은 사장님 목업 기반 확정이었으므로, 교체 후
  스크린샷 세트로 확인받는다.
- 작업 위치: `naraka-home-wt` 워크트리(feat/naraka-home).
