## 3. 구조

### 3-1. 책과 쪽 = URL

데스크톱 펼친 양면 하나 = URL 하나. 모바일은 같은 URL을 한 쪽으로 보여준다.

| 책 | 표지 | 쪽 순서 (URL) |
|---|---|---|
| 홈 | 붉은 도장 「나라카」 책 | `/` 오늘의 나라카(오늘 출근 요괴·진행 중 이벤트) → `/?p=calendar` 이달 달력·출근표 → `/?p=news` 새 소식 5개 → `/?p=visit` 방문 안내 요약·예약 |
| 소개 | 가죽 연대기 | `/about` 나라카란 → `?p=1` 프롤로그(13) → `?p=2` 1막(1~4) → `?p=3` 2막(5~8) → `?p=4` 3막(9~12) → `?p=5` 피날레(14~17) + 인스타 링크 |
| 오시는 길 | 지도책 | `/location` 지도·주소 → `?p=hours` 영업시간·휴무·찾아오는 법 → `?p=reserve` 예약 안내 |
| 메뉴 | 레시피 북 | `/menu` 목차(분류) → `/menu?c=<분류>` 분류마다 한 쪽 |
| 요괴 | 이력서 철 | `/staff` 명단 → `/staff/[id]` 이력서 양식 한 쪽(실사 사진, 붉은 「종신」 도장) |
| 공지 | 관보 묶음 | `/notice` 목록 1쪽 → `?page=2`… → `/notice/[id]` 상세 |
| 이벤트 | 달력 장부 | `/events` 이달 달력 → `?page=1`… 목록(진행 중 → 예정, 지난 것은 목록 뒤쪽) → `/events/[id]` 상세 |
| 게임 | 마작 장부 | `/games` 목차 → `/games/[id]` (주식 이벤트: 소개·기록·`/event` 입장 링크) |

- 주식 앱 `/event/*`, 어드민, API는 책 밖 — 변경 없음.
- 새 라우트: `/staff/[id]`, `/games/[id]`. 나머지는 기존 라우트에 쿼리로 쪽을 붙인다.
- 목록 쪽 크기: 공지·이벤트 한 쪽에 8개.

### 3-2. 책 순서표 (manifest)

```ts
type BookId = "home" | "about" | "location" | "menu" | "staff" | "notice" | "events" | "games";
type BookPageRef = { href: string; tab: string; kind: "toc" | "list" | "detail" | "content" };
// 서버 전용 — DB에서 오는 쪽(공지·이벤트·요괴·메뉴 분류·게임)은 여기서 읽어 만든다
async function getBookManifest(book: BookId): Promise<BookPageRef[]>;
```

- `src/lib/book/` — 순수 함수(쪽 인덱스 찾기, 다음·이전, 넘김 방향 판정, 후루룩 장 수, 인트로 재생 조건). vitest 대상.
- `src/services/bookManifestService.ts` — `getBookManifest`. 기존 `homeContentService`를 재사용.
- 순서표가 결정하는 것: 스크롤 다음·이전 / 인덱스 탭 목록 / 목록→상세 후루룩 장 수.
- URL → 책 판정은 경로 첫 세그먼트로 한다(`/` = 홈).

### 3-3. 화면 뼈대

```
(home)/layout.tsx (서버)
 └ BookShell (클라이언트, 레이아웃에 상주 — 이동해도 유지)
    ├ TopBar: 로고(→ 홈 책) · 예약하기 · 메뉴 토글
    ├ ShelfDrawer: 책등 8개 서랍 (role=dialog)
    ├ IntroSequence: 영상/정지 인트로 (조건부)
    ├ BookStage: 책상 + 펼친 책 + 넘김 연출 + 입력 처리
    │   ├ IndexTabs (데스크톱)
    │   └ PageFooter (모바일: "3 / 7" · 이전·다음 · 목차)
    └ {children} = 현재 쪽 (서버 컴포넌트가 DB로 채움)
```

- 각 쪽 페이지는 `<Spread left={...} right={...} />` 틀로 내용을 그린다. 데스크톱은 좌(삽화·제목)·우(본문) 양면, 모바일은 위아래로 쌓은 한 쪽.
- 쪽 페이지는 자기 책의 순서표를 서버에서 받아 `BookStage`에 넘긴다(현재 인덱스·다음·이전·탭).
- 넘김: `BookStage`가 이동 직전 쪽의 DOM 스냅샷(직전 `children` 요소)을 잠깐 보관하고, 새 쪽과 겹쳐 `rotateY` 넘김을 그린 뒤 버린다. 스냅샷은 `aria-hidden`·`inert`.
- 다음·이전 쪽은 `router.prefetch`로 미리 받는다.

## 4. 연출

### 4-1. 진입

| 상황 | 동작 |
|---|---|
| 세션 첫 방문 + `/` 진입 | 인트로 영상 → 마지막 프레임 위에 CSS 책을 겹침 → 손(15)이 표지를 펼침 → 홈 첫 쪽 |
| 같은 세션 재진입 `/` | 책상 위 닫힌 책이 펼쳐지는 장면만 (~1초) |
| 딥링크 (`/`가 아닌 경로, 또는 `/?p=`) | 인트로 없이 해당 쪽이 펼쳐진 상태로 시작 |
| `prefers-reduced-motion` | 연출 없이 펼쳐진 상태. 넘김은 150ms 페이드 |

- 세션 판정: `sessionStorage` (try/catch — 막히면 "재진입"으로 취급해 긴 인트로를 반복하지 않는다).
- 인트로 중 우하단 **건너뛰기** 상시 노출.
- 영상이 3초 안에 재생되지 않으면(느린 망·`saveData`·자동재생 차단) 자동 건너뜀. 로딩 중엔 지옥문 정지 그림(`01-gate`).

### 4-2. 인트로 영상 (힉스필드)

- 클립 3~4개로 나눠 각각 시작·끝 프레임을 고정한다: ① 지옥문 열림(`01-gate` → 문 열린 상태) ② 방 진입(→ `02-office`) ③ 책장 확대·책 꺼냄(→ `03-shelf`) ④ 책상(→ `13-desk`).
- **마지막 프레임 = `13-desk`와 동일**해야 CSS 책이 이음새 없이 이어받는다.
- 데스크톱 16:9 / 모바일 9:16 두 벌, 각 ≤ 3MB, `<video muted playsinline>` + `media` 쿼리로 한 벌만 받는다.
- 영상이 나오기 전엔 같은 그림 겹을 CSS로 확대·이동하는 정지 인트로로 대체한다(실패 시 영구 대체안이기도 하다).

### 4-3. 쪽 넘김 (같은 책)

- 입력 — 데스크톱: 휠·←→·PageUp/PageDown·인덱스 탭 / 모바일: 위아래 스와이프·이전·다음 버튼.
- 휠 잠금: 한 번 넘긴 뒤 넘김 종료(~0.6초)까지 추가 입력 무시(트랙패드 관성 방지).
- 쪽 안 스크롤이 남아 있으면 먼저 스크롤. 끝에 닿은 뒤 **한 번 더** 굴려야 넘김.
- 후루룩: 목록→상세·탭 점프처럼 2쪽 이상 건너뛸 때 중간 쪽은 불러오지 않고 빈 종이 장 3~5장을 넘긴다. 총 ≤ 0.8초.
- 넘김 = 한 장(앞·뒷면 판)이 제본선 축으로 `rotateY` + 그라데이션 그림자. `transform`·`opacity`만 애니메이트.

### 4-4. 책 교체 (서랍에서 책등 선택, ≤ 1.5초)

```
표지 덮힘 0.3s → 카메라 후퇴·책장, 덮은 책이 빈칸에 꽂힘 0.4s
→ 손(14)이 새 책 꺼냄 0.4s → 책상에서 손(15)이 펼침 0.4s
```

- 연출 시작과 동시에 새 쪽 데이터 요청(`router.push`). 연출이 끝나면 바로 펼친다. 데이터가 늦으면 펼침 직전에서 대기.
- 연출 중 다른 책 선택 → 현재 연출을 건너뛰고 최종 목적지로.
- 서랍에서 지금 펼친 책의 자리는 빈칸으로 보인다.

### 4-5. 뒤로가기

모든 쪽 이동은 URL 변경이다. 뒤로가기는 순서표 기준 반대 방향으로 넘기고, 다른 책으로 돌아가면 책 교체 연출.

## 5. 실패·폴백·접근성·성능

### 5-1. 실패

| 상황 | 대응 |
|---|---|
| 인트로 영상 실패 | 조용히 건너뛰고 책상 펼침부터 |
| 쪽 데이터 오류 | 그 쪽만 빈 상태 쪽(원화 14 삽화 + "잠시 후 다시"). 책·메뉴는 정상 동작 |
| 없는 쪽 (`/notice/999`) | 그 책의 목차 쪽 + 안내 문구 |
| 그림 에셋 미도착 | 라벨 붙은 단색 판으로 대체 — 에셋 전에도 전 기능 개발·검증 가능 |

### 5-2. 접근성

- 쪽 내용은 전부 HTML. 넘김 스냅샷·빈 종이 장은 `aria-hidden` + `inert`.
- 쪽 전환 후 새 쪽 제목(`h1`)으로 포커스 이동 + `aria-live="polite"` 영역에 "요괴 책, 3쪽 / 7쪽".
- 서랍: `role="dialog"`·포커스 트랩·Esc 닫기·닫으면 토글로 포커스 복귀.
- 인덱스 탭·이전·다음·건너뛰기: 키보드 조작, 터치 타깃 ≥ 44px.

### 5-3. 성능 예산

- 인트로 영상: 화면에 맞는 한 벌만, 각 ≤ 3MB.
- 첫 화면 그림(책상·홈 표지·쪽 장식) 합계 ≤ 1MB, 전부 WebP.
- 방·책장·다른 표지 그림은 인트로 재생 중 백그라운드 프리로드.
- 새 의존성은 `motion` 하나. three 계열 제거로 홈 번들 약 150KB(gzip) 감소.
