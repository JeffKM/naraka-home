# 책상 위 히어로 설계 (여정 스크럽 대체)

날짜: 2026-08-26 · 브랜치: feat/naraka-home (PR #80)

## 배경·문제

홈 최상단의 스크롤 스크럽 여정(릴스 74~80초 역재생 72프레임, 360vh sticky)은 다음 세 가지가 겹쳐 폐기한다.

1. **첫 화면 역할 부적합** — 6초 연출에 잡혀 이름·달력·소식이 화면 서너 장 아래로 밀린다.
2. **화질·레터박스** — 9:16 세로 프레임을 데스크톱 가로 화면에 세워 좌우 여백과 저해상 확대가 어색하다.
3. **내용** — 인스타→책상→액자 진입 연출 자체가 매력이 약하다.

## 결정: A. 책상 위 히어로

영상의 마지막 장면(밤의 책상 위 인스타 화면)을 **가로 레이아웃으로 다시 짓는다.** 세로 영상은 "책상 위 폰 화면"이라는 맥락을 얻어 레터박스가 아니라 의도가 된다.

### 구성 (데스크톱 ≥ md)

```
┌────────────────────────────────────────────────────────┐
│  [//// //]                                   ┌──────┐   │
│  나라카                                      │ 인스타│   │
│  요괴들의 도시, 나라카에 오신 것을 환영합니다   │ 프레임│   │
│  [달력·출근표 보기] [나라카 이야기]            │(루프) │   │
│  ▭ 명패                                      └──────┘   │
│  ─── 책상 상판(로즈우드) ── 잉크병 · 방석 · 이력서 ────  │
└────────────────────────────────────────────────────────┘
```

- 배경: `--home-void` → 하단 `--home-rosewood-deep` 상판 띠(그라데이션)로 "밤의 책상".
- 좌: 탈리 마크, h1 이름, 태그라인, CTA 2개(`#calendar` 기본 / `/about` 프라이머리). 아래 실물 명패 컷아웃.
- 우: `insta-frame.webp`(540×960 알파) 안 창 영역(left 10.19% / top 8.13% / w 79.63% / h 79.64%)에 `<video>` **음소거·자동재생·루프·playsInline**, 포스터 `hero-poster.webp`. 프레임 클릭 → `/about`.
- 소품: 잉크병·방석·이력서 컷아웃을 상판 띠 위에 배치(xl 이상). 스크롤 하이재킹 없음, 높이 auto(약 70~80vh).
- 모바일(< md): 인스타 프레임(폭 최대 240px) 위, 텍스트·CTA 아래 1열. 소품 숨김.

### 루프 영상

`public/home/hero-loop.mp4` — 하이라이트 4컷 12초, 540×960, H.264 CRF26 maxrate 1.5M, 무음, faststart (≈0.55MB).

| 순서 | 원본 구간 | 내용 |
|---|---|---|
| 1 | 18.0~22.0s | 멜·옥자 → 옥자 발차기 |
| 2 | 59.0~62.0s | 옥자 물대포 |
| 3 | 66.5~68.5s | 이력서 3장 종신 도장 |
| 4 | 72.5~75.5s | 커튼 단체샷 |

`prefers-reduced-motion: reduce`이면 클라이언트 래퍼(`HeroVideo`)가 재생을 멈추고 포스터만 보인다.

### 정리

- 삭제: `ScrubJourney.tsx`, `public/journey/**`(4.9MB), `StoryTeaser.tsx`(히어로가 인스타 프레임 + `/about` 유도를 대신함 — 홈에 인스타 프레임 두 개 중복 방지).
- `scripts/build-reels-assets.sh`: 여정 프레임·스틸 단계를 히어로 루프·포스터 단계로 교체(BGM 최종본 반영 시 재실행 경로 유지).

### 검증

Playwright: 데스크톱(1440) 홈 첫 화면에 이름·CTA·재생 중 영상이 한 화면에 들어오는지, 모바일(390) 1열 순서, `npm run build`·lint 통과.
